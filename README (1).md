#### 🧠 Depression Detection from Social Media
> *NLP · Text Classification · Mental Health AI*

Built a binary text classifier to detect signs of depression in Reddit posts. Compared four approaches — Logistic Regression, SVM, Random Forest, and a fine-tuned BERT model — with full evaluation using F1-score, ROC-AUC, and confusion matrices. Deployed as a Streamlit app with a confidence score output.

`Python` `scikit-learn` `HuggingFace` `TF-IDF` `BERT` `Streamlit` `NLTK`

[View Repo](https://github.com/codelikeido/depression-detection-social-media) · [Live Demo](#)

#### 🧬 Autism Detection using Machine Learning
> *Healthcare ML · Classification · Feature Analysis*

Developed a machine learning pipeline to predict Autism Spectrum Disorder (ASD) using behavioral and demographic features. Evaluated multiple classifiers, performed feature importance analysis, and examined class imbalance using SMOTE. Goal: support early screening with data-driven tools.

`Python` `scikit-learn` `Pandas` `Seaborn` `SMOTE`

[View Repo](https://github.com/codelikeido/Autism-Prediction-System)

#### 🔧 Predictive Maintenance — Remaining Useful Life (RUL) Estimation
> *Time-Series ML · Regression · Industrial AI*

Estimated the Remaining Useful Life of machine components using NASA's C-MAPSS turbofan dataset and a water pump degradation dataset. Applied Random Forest and XGBoost regressors. Compared ensemble vs. boosting performance across varying operating conditions.

`Python` `XGBoost` `Random Forest` `scikit-learn` `Pandas` `NumPy`

[View Repo](https://github.com/codelikeido/Predictive-Maintenance-)

#### 📄 Resume Analyzer using NLP + LLMs
> *NLP · Prompt Engineering · HR Tech*

Built a tool that parses uploaded PDF resumes, extracts structured information (skills, education, experience) using spaCy and regex, then scores the resume against a given job description using TF-IDF cosine similarity. An LLM layer provides actionable improvement suggestions via prompt engineering.

`Python` `spaCy` `PyMuPDF` `scikit-learn` `OpenAI API` `Streamlit`
